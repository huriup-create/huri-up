# 이름 없는 프로젝트 — STEP 7. 페이지 구조와 사용자 흐름

> MVP 기능이 실제로 놓일 페이지와 이동 흐름을 정리합니다.

**사용자 시나리오**

고3 수험생 서연이 독서실 의자 위에 스마트 방석을 올리고 전원을 켜면, 방석이 사용할 준비가 된다.
서연이 방석에 앉으면, 압력센서가 착석을 감지해 자세 측정이 자동으로 시작된다.
서연이 바르게 앉아 있으면, 압력센서가 앉은 압력 분포를 측정해 서연만의 기준 자세가 정해진다.
서연이 온라인 강의를 들으며 공부하면, 압력센서가 좌우 압력 불균형과 앉은 상태의 변화를 계속 감지한다.
서연이 문제 풀이에 집중하다 몸을 한쪽으로 기울인 채 일정 시간이 지나면, 방석에서 진동이 울린다.
서연이 공부를 멈추지 않은 채 진동을 느끼면, 자기 자세가 무너졌다는 것을 바로 알게 된다.
서연이 스스로 바르게 고쳐 앉으면, 센서가 압력 분포가 돌아온 것을 다시 확인한다. 이렇게 서연은 화면을 보지 않고도 자세를 알아차리고 바로잡는 경험을 하게 된다.

### 방석 준비 
- 목적: 방석 전원을 켜고 앱과 연결해서 쓸 준비가 됐는지 확인한다
- 주요 사용자: 방석을 처음 켜 보는 고3 수험생 서연
- 핵심 행동: 방석 전원 켜기, '기기 연결' 버튼 누르기
- 표시 정보: 방석 연결 상태(연결 중/연결됨), '방석에 앉아 주세요' 안내 문구
- 빈 상태: 연결된 방석이 없을 때: "연결된 방석이 없어요. 방석 전원을 켜고 '기기 연결'을 눌러 주세요."
- 오류 상태: 연결에 실패했을 때: "방석을 찾지 못했어요. 전원이 켜져 있는지 확인해 주세요." 문구와 [다시 시도] 버튼
- 다음 이동: 연결되면 → 착석 확인

### 착석 확인 
- 목적: 방석에 앉고, 방석이 착석을 알아차려 측정이 시작됐는지 확인한다
- 주요 사용자: 방석 연결을 막 마친 고3 수험생 서연
- 핵심 행동: 방석에 앉기, 바른 자세로 몇 초간 앉아 기준 자세 저장하기
- 표시 정보: 착석 감지 상태(대기 중/착석됨), 좌우 압력 분포 미리보기, 기준 자세 설정 진행률, '측정 중' 표시
- 빈 상태: 아직 앉지 않았을 때: "방석에 앉으면 자동으로 측정이 시작돼요." 안내 문구와 방석 그림
- 오류 상태: 착석이 감지되지 않거나 연결이 끊겼을 때: "앉은 게 감지되지 않아요. 방석 가운데에 앉았는지 확인해 주세요." 문구와 [다시 연결] 버튼a진동 알림 발생 표시, 기울어진 방향(왼쪽/오른쪽), 기울어진 채 지난 시간
- 다음 이동: 기준 자세가 저장되면 → 자세 측정(공부 중 화면)

### 자세 측정
- 목적: 공부하는 동안 좌우 압력 불균형과 앉은 자세 변화를 계속 감지한다
- 주요 사용자: 온라인 강의를 듣거나 문제를 푸는 서연
- 핵심 행동: 화면을 보지 않고 공부 계속하기(앱은 백그라운드에서 측정), 필요할 때 측정 일시정지
- 표시 정보: 현재 자세 상태(바름/기울어짐), 좌우 압력 분포, 오늘 착석 시간, 바른 자세 유지 비율
- 빈 상태: 자리를 비웠을 때: "잠시 자리를 비웠어요. 다시 앉으면 이어서 측정해요." 문구와 측정 일시정지
- 오류 상태: 측정 중 연결이 끊겼을 때: "방석과 연결이 끊겼어요. 자동으로 다시 연결하고 있어요." 문구와 [다시 연결] 버튼
- 다음 이동: 한쪽으로 기운 채 일정 시간이 지나면 → 자세 알림 / 자리에서 일어나면 → 측정 종료

### 자세 알림
- 목적: 한쪽으로 기운 채 일정 시간이 지나면 방석 진동으로 자세가 무너졌음을 알린다
- 주요 사용자: 문제 풀이에 집중하다 몸이 한쪽으로 기운 서연
- 핵심 행동: 진동을 느끼고, 공부를 멈추지 않은 채 자세가 무너졌음을 알아차리기
- 표시 정보: 진동 알림 발생 표시, 기울어진 방향(왼쪽/오른쪽), 기울어진 채 지난 시간
- 빈 상태: 알림이 없을 때: 화면에는 '바른 자세 유지 중'만 표시하고 진동은 울리지 않음
- 오류 상태: 진동을 보낼 수 없을 때(방석 배터리 부족 등): "방석 진동을 보낼 수 없어요. 배터리를 확인해 주세요." 문구와 휴대폰 진동으로 대신 알림
- 다음 이동: 자세를 고쳐 앉으면 → 교정 확인

### 교정 확인
- 목적: 바르게 고쳐 앉았을 때 압력 분포가 돌아온 것을 확인하고 알림을 멈춘다
- 주요 사용자: 진동을 느끼고 자세를 고쳐 앉은 서연
- 핵심 행동: 화면 조작 없이 허리를 펴고 바르게 고쳐 앉기
- 표시 정보: '자세가 돌아왔어요' 표시, 기준 자세 대비 압력 분포, 오늘 교정 횟수
- 빈 상태: 오늘 교정 기록이 없을 때: "오늘은 아직 자세 알림이 없었어요. 잘하고 있어요!" 문구
- 오류 상태: 고쳐 앉아도 기준 자세로 돌아오지 않을 때: "기준 자세와 달라요. 기준 자세를 다시 저장할까요?" 문구와 [기준 자세 다시 설정] 버튼
- 다음 이동: 바른 자세가 확인되면 → 자세 측정(공부 계속)

### 측정 종료
- 목적: 공부를 마치면 측정을 끝내고 오늘의 자세 기록을 확인한다
- 주요 사용자: 공부를 마치고 자리에서 일어난 서연
- 핵심 행동: 자리에서 일어나기(자동 종료) 또는 [측정 종료] 누르기, 오늘 기록 보기
- 표시 정보: 오늘 총 착석 시간, 바른 자세 유지 비율, 자세 알림·교정 횟수
- 빈 상태: 측정 기록이 너무 짧을 때: "오늘 기록이 아직 부족해요. 다음에도 방석에 앉아 공부해 보세요." 문구
- 오류 상태: 기록을 불러오지 못했을 때: "오늘 기록을 불러오지 못했어요." 문구와 [다시 시도] 버튼
- 다음 이동: 다음 공부 때 방석에 앉으면 → 착석 확인

**페이지 이동 흐름**

- 방석 준비 : 방석 전원 켜기, '기기 연결' 버튼 누르기 → 연결되면 → 착석 확인
- 착석 확인 : 방석에 앉기, 바른 자세로 몇 초간 앉아 기준 자세 저장하기 → 기준 자세가 저장되면 → 자세 측정(공부 중 화면)
- 자세 측정: 화면을 보지 않고 공부 계속하기(앱은 백그라운드에서 측정), 필요할 때 측정 일시정지 → 한쪽으로 기운 채 일정 시간이 지나면 → 자세 알림 / 자리에서 일어나면 → 측정 종료
- 자세 알림: 진동을 느끼고, 공부를 멈추지 않은 채 자세가 무너졌음을 알아차리기 → 자세를 고쳐 앉으면 → 교정 확인
- 교정 확인: 화면 조작 없이 허리를 펴고 바르게 고쳐 앉기 → 바른 자세가 확인되면 → 자세 측정(공부 계속)
- 측정 종료: 자리에서 일어나기(자동 종료) 또는 [측정 종료] 누르기, 오늘 기록 보기 → 다음 공부 때 방석에 앉으면 → 착석 확인

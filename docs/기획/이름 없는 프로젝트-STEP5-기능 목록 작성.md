# 이름 없는 프로젝트 — STEP 5. 기능 목록 작성

> 기능 1개 = 카드 1장. 어떤 문제를, 사용자가 무엇을 하면, 무엇이 나오는지로 적습니다.

### huri up — 지금 반드시 구현
- 해결 문제: 사용자가 공부를 시작하거나 자리를 비울 때마다 측정 기능을 직접 조작해야 하는 번거로움이 있다.
- 사용자가 하는 것(입력): 사용자가 스마트 방석을 의자 위에 올리고 전원을 켠 뒤 방석에 앉는다. 사용을 마치면 자리에서 일어난다.
- 그러면 나오는 것(출력): 방석 내부의 압력센서가 사용자의 착석 여부를 감지한다. 사용자가 앉으면 자세 측정이 자동으로 시작되고, 일어나면 측정이 중지된다.
- 쓰고 나면 달라지는 것: 사용자는 공부를 시작하거나 자리를 비울 때마다 측정 기능을 직접 켜고 끌 필요가 없어져 더욱 편리하게 방석을 사용할 수 있다.
- 핵심 필수: 아니오 · 난이도: 중간
- 의존 기능: 방석 전원 공급, 압력센서, 착석 여부 판단 기능이 필요하다. 앱 연결 없이도 작동하도록 구현하는 것을 목표로 한다.
- 불확실성: 사용자의 체중 차이와 앉는 위치에 따라 착석 여부를 정확하게 구분할 수 있는지 확인이 필요하다. 가방이나 책 등 물건을 올려놓았을 때 잘못 감지할 가능성도 시험해야 한다.
- 완료 조건: 방석에 앉으면 압력 측정이 자동으로 시작되고, 자리에서 일어나면 측정이 중지되는 것을 확인할 수 있다.
- 분류 사유: 착석 자동 감지는 사용자가 별도의 조작 없이 자세 측정을 시작하고 종료할 수 있도록 하는 첫 단계의 필수 기능이므로 MVP에 포함하였습니다.
